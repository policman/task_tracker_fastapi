ЗАПУСК КОНТЕЙНЕРОВ С НУЛЯ
сборка образов (images) в фоне(-d)
- docker compose up --build -d

--------------------------

НАКАТ МИГРАЦИЙ
Создаем миграцию (если нету)
- docker compose exec api alembic revision --autogenerate -m "Init_DB"

Применяем миграцию
- docker compose exec api alembic upgrade head

--------------------------

ОБНОВЛЕНИЕ ВОРКЕРОВ Celery
- docker compose restart celery_worker

--------------------------

ЛОГИ
Флаг `-f` означает "follow" — логи будут обновляться в реальном времени.
Чтобы выйти из логов, нажми `Ctrl+C`

все сразу
- docker compose logs -f

fastapi
- docker compose logs -f api

Celery
- docker compose logs -f celery_worker

--------------------------

УСТАНОВКА НОВЫХ БИБЛ (Poetry)

Установи её локально на маке, чтобы обновились файлы конфигурации:
- poetry add requests

Пересобери контейнеры, чтобы Docker установил этот пакет внутрь:
- docker compose up --build -d

--------------------------

ОСТАНОВКА ПРОЕКТА
- docker compose down
